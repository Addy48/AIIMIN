# Founder Findings

Only strategic issues. No document hygiene.

### F1 — F-INGRESS legal sequence can be read as Hold → Offer

| Field | Value |
|-------|-------|
| **Section** | §3.1 F-INGRESS-FIRST (propagates to §3.2 F-INGRESS-REPEAT · §3.9 F-CREATE via shared spine) |
| **Concern** | Legal sequence writes `Catch → Settle \| Hold → (Thinking) → Offer*`. Phase 1 Offer Allowed-from for ingress is **Settle** only. P8 sacred spine is Catch → **Settle** → Offer. Hold is honest pending — not an Offer gateway. Forbidden field says “Offer before Settle,” but sequence notation still invites Hold→Offer implementation. |
| **Why it matters** | Freezing this sequence weakens **Settle doctrine** and Exhale honesty: structure Offers could emit while durability/inference is still Hold. Highest-probability constitutional misuse in Phase 2. |
| **Minimal remediation** | Split paths in legal sequence: (a) Catch → Settle → (Thinking overlay)* → Offer* → … ; (b) Catch → Hold → resolve → Settle → then (a), or Idle/Drift/Failed without Offer. Keep Forbidden: Offer before Settle. Do not amend Phase 1 text. |

### F2 — F-STRUCTURE omits Knock interruptibility

| Field | Value |
|-------|-------|
| **Section** | §3.3 F-STRUCTURE |
| **Concern** | Interruption points list Dismiss · Drift · Clarifier only. Phase 1 / P8 forbid Knock only during Catch · Hold · Veil. Post-Settle Offer/Adjust is normally interruptibility-open. F-INGRESS already allows Knock “if window opens later.” F-STRUCTURE is that later window — and is silent. |
| **Why it matters** | Silent policy fork: teams either invent Knock-during-structure bans (new doctrine) or allow Knock without Flow authority. Mixed-initiative predictability breaks. |
| **Minimal remediation** | Founder pick one: (A) add “quiet F-KNOCK if interruptibility open” to F-STRUCTURE interruption points (inherits Phase 1), **or** (B) explicitly forbid Knock during in-progress Adjust (tightening — state as Founder product choice, not “already law”). |
