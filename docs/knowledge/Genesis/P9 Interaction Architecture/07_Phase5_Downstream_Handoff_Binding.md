# Mission

Define **how** frozen P9 Interaction Architecture (Phases 1–4) binds every downstream consumer so product work **expresses and implements** interaction law without amending it.

This phase answers: *What must remain true when building from frozen P9?*  
Not: *What is a Verb / State / Signal?* (Phase 1)  
Not: *What Flow sequence is legal?* (Phase 2)  
Not: *When may Knock / notice fire?* (Phase 3)  
Not: *What is a surface ceiling?* (Phase 4)  
Not: *What UI / visual system is shown?* (UX Architecture · Design System — post-P9)

Phases 1–4 are **immutable**. Phase 5 **inherits** them. Phase 5 does **not** redefine them.

**Axiom:** Downstream MAY express P9. Downstream MUST NOT invent interaction law.

# 1. Terms (operational — not new Ontology)

| Term | Meaning |
|------|---------|
| **Consumer** | Any workstream that builds product behavior or surfaces from P9 (UX Architecture · Design System · Component Library · Hi-Fi · Engineering Specs · QA · Native · `/m`) |
| **Citation** | Explicit reference to a frozen P9 artifact + rule ID when claiming interaction authority |
| **Expression** | Mapping frozen States / Signals / Verbs / Flows / IA / CS into concrete UI, copy, motion, or APIs without changing meaning |
| **Invention** | Creating new interaction meaning, IDs, windows, ceilings, or peer grammars not in frozen P9 |
| **Handoff** | Constitutional transfer of build authority from P9 to post-P9 consumers under these DH rules |
| **Claim** | Any statement that product behavior is P9-conformant |

# 5. Expression vs Invention Boundary

| MAY (Expression) | MUST NOT (Invention) |
|-------------------|----------------------|
| Map States to visual treatments | New States |
| Map Signals to motion / haptics | New Signals that change grammar |
| Layout Catch → Settle spine | Skip Settle or gate Catch |
| Copy that matches Verb truth | Rename Verbs for “clarity” in product law |
| Components for Offer / Adjust | Parallel “suggest” grammar outside F-STRUCTURE |
| APIs that implement F-* | APIs that invent Resume-as-Verb or peer Flows |
| Client feature flags under CS ceilings | Flags that violate `/m` capture-only |

| ID | Rule |
|----|------|
| **DH-30** | Expression is lawful when outcome meaning equals the cited frozen rule. |
| **DH-31** | If removing a UI treatment would change Verb / Flow / IA / CS meaning, that treatment is carrying law — MUST cite; MUST NOT invent. |
| **DH-32** | Decorative treatment that does not change meaning needs no P9 citation. |
| **DH-33** | Ambiguity between expression and invention resolves against invention — stop and cite Founder ADR path. |
