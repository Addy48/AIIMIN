# 2. Scope

## Phase 5 is responsible for

1. **Consumer catalog** — who must obey P9 (UX Architecture · Design System · Components · Hi-Fi · Engineering Specs · QA)

3. **Non-amendment / non-reinterpretation rules**
4. **Conflict order for downstream** (restate P8 > Phase 1 > 2 > 3 > 4 > Phase 5 handoff)
