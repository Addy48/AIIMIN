# 2. Scope

## Phase 3 is responsible for

1. **Initiative model depth** — when Human / System silent / System Knock / System Clarifier / Platform may open attention (extends Phase 2 matrix; does not rewrite Flow openings illegally)
2. **Interruptibility windows** — open / closed / quiet rules across States and Flow segments (must honor Catch · Hold · Veil · Breath · active F-STRUCTURE Adjust bans)
3. **Attention law** — one Anchor / focal turn; Latent never self-promotes into Catch/Veil; peripheral vs focal Coach
4. **Notification interaction** — deserve-attention, delivery cadence bounds, deep-link into grammar, anti-nag, relationship to Knock (FQ-P2-03 depth)
5. **Clarifier initiative bounds** — when Blocked Ask may fire post first Settle; anti-interrogation parade
6. **Suggestion / Coach session rules** — provenance, dismiss-closes-session, re-knock bans (inherit Phase 1/2; specify initiative timing)
7. **Failure / recovery attention** — when Failed / Conflict / Offline may claim focus vs stay peripheral
8. **Deferred product policies that Phase 3 may host** — only if they are initiative/attention scoped (not Flow taxonomy; not surface contracts)
