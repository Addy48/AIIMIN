## Decision

Authorize correction of **address-only** chapter references in frozen Chapters 01, 02, and 15 that still use the pre-renumber chapter map.

This ADR is the single authoritative migration ledger for those references.

**Doctrine is unchanged.** Only chapter numbers, chapter titles, dependency references, terminology references, excludes, and invariant cross-references may be corrected under this ADR.

## Context

Early P8 drafts numbered chapters differently (e.g. Core Objects as Ch 03, Capture as Ch 05, Navigation as Ch 07, Implementation Constraints as Ch 21). Final frozen TOC remapped those owners. Frozen Ch 01/02/15 retained stale addresses. Publication verification BLOCKER-01/02 required a complete ledger and application.

Prior partial note covered only linking (Ch 03→05) and lockup routes (Ch 07→04). This ADR supersedes that partial note with the full map.
