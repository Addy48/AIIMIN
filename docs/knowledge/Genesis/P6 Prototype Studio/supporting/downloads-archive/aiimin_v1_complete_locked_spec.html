📋
Today Opens first
Your daily ground truth
  • Date + day + sem week number at top (e.g. "Thursday · Week 14 of Sem 6")
  • Placement countdown: "26 days left" — always visible, can't ignore
  • Today's classes: auto-loaded from your timetable (enter once per sem). Shows time + subject + room. Greyed out as they pass.
  • Mess menu: you upload a photo (weekly or daily). Today's meals shown as image card. Tap to expand.
  • Top 3 tasks: pulled from Work tab. If not set, shows "Tap to plan today" — guilt prompt.
  • Did you eat breakfast? Single toggle. Tracks your skip pattern passively.
  • Steps: live sync from Nothing Phone health. Progress ring vs 10k goal.
  • Mood check-in: 1 tap. 5 icons (terrible / low / okay / good / great). Takes 1 second.
  • Sleep last night: tap to enter hours. Pre-filled if you logged bedtime.
  • Gym today? Binary toggle. Yes = +1 to gym streak. No = nothing, no guilt.
  • Quick money add: floating ₹ button → amount → category → done in 3 taps.
  • Night mode (10pm trigger): "Plan tomorrow" card appears. Tap → pick 3 tasks for tomorrow from backlog. 2 min ritual.
💼
Work Core
Tasks + Placement — your engine
  • Two sections on same screen: Today's Tasks (top) and Placement War Room (bottom, expandable)
  • Today's tasks: 3 max active. Checkbox to complete. Swipe left to push to backlog. Swipe right to delete.
  • Add task: title, optional due date, optional note. That's it. No tags, no priorities, no complexity.
  • Backlog: all other tasks. Sorted by date added. Pull to active by tapping.
  • Placement — DSA roadmap (built-in, not generic): Arrays, Strings, Hashing, Two Pointers, Sliding Window, Binary Search, LinkedList, Stack, Queue, Trees, BST, Heap, Graphs, DP Basics, DP Advanced. Each has 5–10 subtopics with checkboxes. Problems solved counter per topic.
  • Placement — Applications table: Company name, role, date applied, status (applied / OA received / OA done / interview / offer / rejected). Add new in 4 taps.
  • Placement — Resume tracker: last updated date, version note, link or file reference.
  • Placement — Interview log: company, round type (HR/tech/coding), date, outcome, 1-line note.
  • Placement — Daily target: you set "solve X problems today" — checkmark when done.
  • Sem end date set once: countdown visible on Today tab.
💰
Money Core
Both accounts, full picture
  • Top card — Net Balance: ICICI balance (manual update) + Airtel balance (manual update) = total shown large. Green if positive, red if negative.
  • Two account tabs: ICICI (parents' money) and Airtel (your earnings). Each has its own transaction list.
  • Transaction add (3 taps): amount → category → account → done. Optional note and photo.
  • Categories (India-relevant): Food, Mess, Canteen, Travel (Uber/auto), Shopping, Entertainment, Subscriptions, Fees, Sent to person, Received from person, Other.
  • Monthly spend summary: total this month, category breakdown as horizontal bars, vs last month delta.
  • Weekly cashflow chart: 7-day spend line chart. Today highlighted.
  • Money lent log: Name, amount, date given. Tap to mark returned. No reminders — just your record.
  • NET WORTH tracker: separate section. You enter: cash in hand, ICICI balance, Airtel balance, MF value (Groww/Zerodha — manual), gold value (grams × live price), any other asset. System computes total. Logged monthly — you see your net worth grow over time as a chart. This is the wealth-building visual.
  • SIP log: Fund name, amount per month, start date. Running total invested shown. Simple tracker to make the habit real.
  • Upcoming expenses: list of known future spends (exam fees, subscriptions, EMIs). Date + amount. Shows in Today tab if due within 3 days.
  • Gold/Silver price reference: live price shown (API). Your holdings × price = current value. Feeds into net worth.
  • Export to CSV: any account, any date range.
📝
Notes Important
Brain dump, voice, titled notes
  • Three types in one tab, toggled at top: Quick Dump / Voice / Notes
  • Quick Dump: single running document. Tap anywhere → type. Autocorrect fully on. Saves every keystroke. Timestamped entries separated by line. No title needed. Just dump and go.
  • Voice: hold mic button → speak → transcribed via Gemini API → saved with timestamp. Handles your spelling issues by speaking instead.
  • Titled Notes: Google Keep style. Title + body. Color coding (6 colors). Pin important. Search across all. Images attachable.
  • Search: global search across all three types in real time.
  • Mess menu storage: upload images here tagged as "Mess Menu" — Today tab pulls from here.
  • Class timetable: editable here (text form) — Today tab reads from this.
📊
Insights V1 basic
Your data, made readable
  • Daily score (0–100): computed from: tasks completed (40%) + mood (20%) + steps (15%) + sleep (15%) + gym (10%). Big number. Gold colored. History chart — last 30 days.
  • Mood history: last 30 days calendar. Color per mood rating. See your pattern.
  • Sleep chart: hours per night, last 14 days. Average shown.
  • Steps history: 7-day and 30-day. Days you hit 10k highlighted.
  • Gym streak: current + longest. Calendar showing gym days.
  • Money insight: this month vs last month spend. Top spending category. Biggest single spend.
  • Net worth chart: monthly snapshots over time. The wealth line going up is the most motivating visual in the app.
  • Placement progress: DSA % complete, applications sent count, this week's problems solved.
  • Recovery streak: visible here (not just in the locked tab) — current streak shown as a number with a simple line graph. No detail — detail is in the locked tab.
  • Screen time note: manual entry only (Nothing Phone doesn't expose this to third-party apps easily). You enter it yourself if you want to track.
🔒
Recovery Biometric locked
Hidden tab — lock icon only in nav
  • Opens only after biometric/PIN. Shows nothing until authenticated. Nav shows only a lock icon — no label.
  • Current streak: large, prominent. Days and hours.
  • Last reset: exact date and time.
  • Longest streak: shown as "personal best" — gives you something to beat.
  • Log urge: one tap. Then: trigger type (Boredom / Stress / Loneliness / Content encountered / Physical / Late night / Multiple). Time auto-logged. Optional note (text or voice).
  • Log reset: tapping this resets streak. Before resetting, shows current streak ("You're about to reset a X-day streak"). Asks trigger. Saves everything — no data is lost.
  • Weekly heatmap: urges by hour of day across 7 days. Shows your peak risk windows clearly. E.g. "11pm–1am is your highest risk window."
  • Trigger breakdown: which type appears most. Pie breakdown. Updated as you log.
  • 30-day history: days clean shown as green, resets as red dots. Not a calendar of shame — a calendar of data.
  • Streak milestones: silent internal milestones. At 7, 14, 21, 30, 60, 90 days — a simple text message appears. No notification, no external signal. Just there when you open the tab.
  • No quotes. No motivational content. No emoji. Pure data.

Architecture: App and web are the same system. You log on app, see it on web instantly. You plan on web, it shows on app in morning. Everything lives in Supabase.
Tech stack confirmed
  • App: React Native (Expo) — Android first. Nothing Phone 2 compatible.
  • Web: existing React app on Vercel. Extend existing codebase.
  • Backend: existing Express on Railway. Add new API routes.
  • Database: existing Supabase PostgreSQL. New tables added.
  • Auth: existing Google OAuth. App uses same auth, deep-linked.
  • AI/voice: Gemini 1.5 Flash (free tier) — voice transcription + (V2) weekly reports.
  • Gold/silver price: metals-api.com free tier or scrape RBI reference rate.
  • Steps: Android Health Connect API — read steps passively.
  • Notifications: Firebase Cloud Messaging (FCM) — free, Android native.

3 notifications. That's all.
  • 8:00 AM: "Good morning. [X] classes today. Top task: [first task]. [Y] days to placement."
  • 10:00 PM: "Plan tomorrow. What are your 3 tasks?" — deep links to night planning screen.
  • Custom (you set time): "DSA time." — your daily coding reminder. You pick the time.
Recovery data security: recovery_logs table has RLS policy — only your user_id can read/write. Supabase encryption at rest. On device, Recovery tab requires biometric before rendering any data. If auth fails, blank screen.
