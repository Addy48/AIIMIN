Key correction: Placements don't start in 1 month. They start in 7th/8th sem. You have 1 month of sem left, then 2.5 months holidays — that's your real opportunity window. Use it right and you go into 7th sem prepared.
Your 3 phases — AIIMIN is built around these
Phase 1 — Now → 1 month · 6th Sem finish
Survive + start the system
Exams, submissions, whatever is pending. AIIMIN's job: daily task list, money tracking, keep the recovery streak alive. Don't expect habit formation yet — just get to sem end without chaos.
Today tab daily Money log Recovery streak Notes dump
Phase 2 — 2.5 months holidays · The real build period
This is where you actually transform
No classes. Time is yours. This is where DSA starts seriously (3–4 hours daily), gym becomes consistent, sleep fixes, spending monitored, SIP started, net worth baseline set. AIIMIN becomes your full operating system during this period. If you use these 2.5 months right, you go into 7th sem as a different person.
DSA daily (roadmap active) Gym 4–5x/week Sleep fixed SIP started Recovery 60-day target Habits locked in Net worth baseline
Phase 3 — 7th + 8th sem · Placement window
Execute — system runs on autopilot
DSA done, habits formed, money tracked, body built. AIIMIN in this phase tracks placement applications, interview prep, daily targets. The system you built in Phase 2 carries you here.
Placement war room active Applications CRM Interview prep notes Habits on autopilot AI weekly reports (V2)
Why this matters for the build: The holiday period is the most important thing to design for. The system needs to be ready BEFORE sem ends so you hit Day 1 of holidays with a working app. That's your real deadline — not placements.

Tab 1 — Today
Opens first, every day ▶
Identity anchor line V1
Top of screen. One "I am" statement rotating daily. You write these once in Identity section of web dashboard. Reminds you who you're becoming before the day starts.
Daily score — hero number V1
0–100. Gold. Computed: tasks done (35%) + mood (20%) + sleep (15%) + steps (15%) + gym (10%) + meals eaten (5%). Visible on home screen widget too.
Placement countdown V1
"X days of holidays remaining" during break. "X days to placement season" during 7th sem. Always visible below score. Contextual based on which phase you're in.
Today's classes V1
Auto-loaded from timetable (enter once per sem). Shows time + subject. During holidays: shows "Holiday — free day" with suggested focus area (DSA / gym / rest based on your streak).
Mess menu V1
Photo card. You upload weekly. Shows breakfast / lunch / high tea / dinner for today. Tap to expand full image. During holidays: shows blank with "Cook or order" placeholder.
Top 3 tasks V1
Pulled from Work tab. If not set, shows "Plan your day →" tap prompt. Checkbox to complete inline. Completing all 3 triggers a subtle animation.
Mood — 1 tap V1
5 options with face icons: Struggling / Low / Okay / Good / Thriving. Tap once, done. Background of card shifts color. No text input required.
Sleep logged V1
Hours + optional quality (1–5). Pre-fills if you set bedtime last night. During holidays: no alarm pressure, but still log to track drift.
Gym toggle + Steps V1
Gym: binary yes/no. Steps: synced from Health Connect, shows ring vs 10k. Both in same compact row.
Meals eaten today V1
Breakfast / Lunch / Dinner toggles. Tracks your skipping pattern. During sem: shows mess meal reference. During holidays: just log what you ate (one word).
Quick money add V1
Floating ₹ button always visible on Today. Tap → amount → category → account (ICICI/Airtel) → done. 3 taps. Most used interaction after habit tick.
Night planning ritual V1
10pm notification → "Set up tomorrow" → pick 3 tasks from backlog → done. 2 minutes. Next morning Today tab is pre-loaded.
Recovery mode toggle V1
Moon icon top-right. Strips Today to bare minimum: 3 habits + mood only + identity line. For low-energy or bad days. No scores visible.

Tab 2 — Work
Tasks + DSA + Placements ▶
Daily task list — max 3 active V1
Checkbox to complete. Swipe left → backlog. Swipe right → delete. Add task: title + optional due date. That's it. No priority tags, no labels — just do it.
Backlog V1
Everything else. Tap any item to pull into active. Sorted by date added. During holidays: your DSA topics and learning goals live here.
DSA Roadmap — built in V1
Full roadmap pre-loaded: Arrays → Strings → Hashing → Two Pointers → Sliding Window → Binary Search → LinkedList → Stack → Queue → Trees → BST → Heap → Graphs → DP Basics → DP Advanced. Each has 6–12 subtopics as checkboxes. Problems solved counter per topic. % complete shown.
Daily DSA target V1
You set "X problems today." Checkmark when done. Feeds daily score. During holidays: this is the main work metric. During sem: secondary.
Applications CRM V1
Company, role, date applied, status (applied / OA / OA done / interview / offer / rejected). Add in 4 taps. Color-coded status badges.
Interview log V1
Company, round (HR/tech/coding), date, outcome, notes. Reference before each interview.
Resume tracker V1
Version number, last updated date, link. Simple. Know which version you sent where.
Holiday mode flag V1
When sem ends, system switches to holiday mode. Placement countdown becomes "days of holiday left." DSA daily target becomes primary metric. Gym target becomes secondary.

Tab 3 — Habits
Execution first, always ▶
Execution-first view V1
Opens to today's habits. Not settings. Circular 48px tap targets. Thin ring on incomplete, gold ring fills on complete (300ms spring animation). Haptic on complete.
Three routine blocks V1
Morning / Afternoon / Evening. Collapsible. Each habit belongs to a block. Completion ritual: when full block done, brief warm shimmer + text "Morning done ✓".
Your starter habits (pre-loaded for you) V1
Morning: Wake before 8am, Skincare, 10 mins DSA warm-up. Afternoon: 10k steps check, Eat lunch. Evening: Gym, Journal 2 lines, Plan tomorrow. You edit/add from here.
Habit creation V1
Name, routine assignment (morning/afternoon/evening), frequency (daily / weekdays / custom). Identity link optional (which "I am" statement does this serve).
Streak calendar V1
Per-habit monthly grid. Gold = done, empty circle = missed. No shame colors. Pattern is the insight.
Skip reason (optional) V1
On skip: "why?" — Tired / Busy / Forgot / Rest day / Other. Optional, 1 tap. Feeds holiday analysis: "you skip gym most on rainy days."
Chain Reaction Score V1
When you complete your "domino habit" (set in Identity), all subsequent habit completions that day get a chain bonus to daily score. Visible in Insights.

Subscription tracker V1
List of recurring payments. Monthly/yearly. Next renewal date. Annual total. 3-day alert. "You're paying ₹X/year total on subscriptions."
Profit First buckets V1
When income comes in (Airtel variable), allocate: Needs 50% / Savings 20% / Investments 10% / Wants 20%. Simple split shown visually. Not forced — just visible.
