## Hard locks honored

- Palette: dark `#1a1a1a` / `#2d2d2d` / `#ff6b35` / `#10b981` / `#6b7280`
- Light: warm ivory canvas + white surfaces (Palette.md)
- Brand: Human Momentum; mark ≠ wordmark jobs preserved in mapping docs
- Anti-clone: no Notion, Linear, Material template, Apple imitation, widget dashboard
- Kill list: no social feed, no clinical AI, no streak-shame chrome
- Capture first; structure later; Life Score honest

## Primary question answer

**Would people remember AIIMIN one year later?**

Only if the product feels like a **private operating system for one’s day** — not a productivity suite. This studio ships that thesis as Living Momentum OS.
