# 02 — Design Decisions

## Product concept lock

**Name:** Living Momentum OS  
**Brand frame:** Human Momentum  
**Primary emotion:** Calm command — quiet confidence, never hustle chrome  
**Platform first:** Android companion that feels whole

## Information architecture lock

| Primary (bottom nav) | Job |
|----------------------|-----|
| Today | Living day surface — habits, next focus, money pulse, AI nudge |
| Knowledge | Memory capture — journal + notes as one layer (tabs, not apps) |
| Capture FAB | Intent utterance — routes to habit / journal / finance / note / event |
| Timeline | Chronological life graph — honest history |
| More | Family, Finance, Documents, AI, Search, Settings, Profile |

## Surface jobs (one job each)

| Surface | One job |
|---------|---------|
| Today | Act on this day |
| Knowledge | Capture and revise personal memory |
| Documents | Store and retrieve files / vault docs |
| Family | Shared care + private vault trust |
| Finance | Log and see money truth |
| Timeline | Remember what happened |
| AI | Ask / review / act with confidence chips |
| Search | Recall across the graph |
| Settings | Control system safely |
| Profile | Identity + honest progress (no shame badges carnival) |
| Onboarding | Three beats to first capture |
| Auth | Trust entry (Google / email / biometric later) |

## Visual decisions

| Decision | Choice | Why |
|----------|--------|-----|
| Color | Locked palette | Product lock |
| Light canvas | Warm ivory `#EDE4D3` / `#f4efe6` family | Palette.md — not cream-terracotta editorial cliché when paired with charcoal ink + orange action |
| Type | Familjen Grotesk (display) + Figtree (UI) | Existing brand waitlist system |
| Cards | Sparse; 1px borders; no nested cards | Product register |
| Accent use | Primary actions, selection, FAB only | Restrained strategy |
| Icons | Stroke 1.75–2; consistent optical size | Not emoji UI |
| Illustration | Minimal mark-based; no stock 3D blobs | Handcrafted |

## Interaction decisions

| Pattern | Law |
|---------|-----|
| Capture | FAB → sheet → chips confirm inference |
| Toggle | Optimistic habit complete |
| Destructive | Confirm sheet (typed only for account delete — mapped, not fully prototyped) |
| Navigation | Crossfade screens ≤220ms; sheets rise; drawer from leading edge |
| Empty | Teach next action + shortcut hint |
| AI | Suggest → chip → never silent wrong |

## Explicit anti-decisions

- No Tasks tab as primary  
- No Projects board as primary  
- No Dashboard of random widgets  
- No purple AI glow  
- No bounce/elastic motion  
- No clinical copy (“depression score”, “diagnosis”)  
- No public social

## Why reviewers should believe craft

Hierarchy starts with **Today’s next action**, not chrome. Identity is orange-on-charcoal with Familjen mark. Motion is state, not spectacle. Memory (Timeline/Knowledge) gives long-term soul. Trust surfaces (Family vault PIN, export language in Settings) are visible.
