## Moments users may smile

- Tour line: “without a second productivity cult”
- Honest phone copy admitting desktop OS
- Micro-task that is actually micro
- Warm ivory light mode (distinctive calm)

## Fake delight (avoid amplifying)

- XP fireworks without meaning
- LIVE badges
- Emoji onboarding candy
- Demo wins
- Purple GuestTour gradients

---

## Feeling understood (highest value delight)

Occurs when system language matches inner state:
- Vent → journal without mode homework
- Urge → discipline toolkit
- “I spent money” → confirm chip not ledger exam

**Gap:** Understanding is promised in doctrine and Tour more than delivered in default Today.
