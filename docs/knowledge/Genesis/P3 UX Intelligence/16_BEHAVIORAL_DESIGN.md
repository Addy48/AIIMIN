
---

## Habits & daily engagement

| Mechanism | Effect | Risk |
|-----------|--------|------|
| Habit toggle | Strong implementation intention support | Over-tracking trivial habits |
| Streaks | Consistency cue | Shame on break |
| Heatmap | Visual progress | Perfectionism |
| Logger | Flexible capture | Misroute discourages retry |
| PulseCheck | Trigger daily open | Nagging |
| XP/ranks/quests | Extrinsic boost | Theater vs sincerity |
| Life Score | Outcome feedback | Guilt if opaque |
| Monday Insight | Weekly reflection habit | Ignored if generic |

**Protect:** toggle. **Govern:** streaks/XP. **Invest:** insight quality + score clarity.

---

## Weekly / long-term engagement

North star: **Weekly Active Capture (WAC) 60%** among activated @ launch+90d.
Supporting: Day 7 return &gt;40%; journal funnel &gt;70%; median interactions → 5.

**Long-term identity formation:** Life Arc + honest Score + private journal archive.
**Long-term failure mode:** Feature tourism (Lab, Design Lab) without capture habit.

---

## Feedback loops

| Loop | Quality |
|------|---------|
| Habit → streak UI | Fast |
| Capture → Score delta | Medium — must be understandable |
| Journal → AI tags | Medium — consent/correct |
| Finance → Reports | Slow analytical |
| Discipline slip → recovery CTA | Designed; keep short |
| Goal milestone → Score | Indirect |

---

## Motivation types

- **Identity:** Arc, OS-ID, Human Momentum — preferred
- **Mastery:** Focus, Lab skills, Career ATS — selective
- **Autonomy:** Nav pins, widgets — double-edged (customization trap)
- **Extrinsic:** XP — limit
- **Social:** Mostly rejected (good for anti-persona)

---

## Retention threats (behavioral)

1. Activation burnout before habit forms
2. Phone-only users cannot complete Home ritual (no habit create)
3. Guilt Score → avoidance coping (stop opening)
4. Engagement chrome teaches wrong habit (customize forever)
5. Notification absence → rely on user memory (monthly lapse)

---

## Reflection & goal reinforcement

Reports/Patterns exist; narrative weekly digest still target-state.
Goals reinforce when linked to Focus/Habits — linkage UX still user-invented.

---

## Sparring conclusion

Gamification without compression is **engagement cosplay**. Compression without feedback is **a notes app**. AIIMIN’s five-year behavior design must ship **both**, with Score sincerity above XP.
