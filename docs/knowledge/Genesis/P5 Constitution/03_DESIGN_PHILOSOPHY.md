## Purpose

Define what makes AIIMIN recognizable, human, intelligent, calm, and premium — and which visual and interaction ideas are permanently rejected.

## Reasoning

AIIMIN already killed electric blue + Outfit, forest-green WaitlistBrand as `/brand`, purple OAuth chrome, GoodNotes handwriting, and Quick Capture tile grids. Design philosophy must explain *why* those deaths were correct and what must survive every craft pass.

## Evidence

Design History; Palette lock; Brand Human Momentum; Craft motion discipline; Product anti-looks; frontend design hard rules; nav lockup; `AIIMIN_VISUAL_CONTEXT/` (Brand DNA, Design Principles, logo-off verdict); `AIIMIN_UX_CONTEXT/` (first impression, AI slop, platform continuity).

## What makes AIIMIN immediately recognizable

**Logo-off test (from Visual Intelligence):** brand/ritual surfaces currently pass; dense Life OS grids often fail toward generic dark SaaS. Constitution requires raising dense pages to pass — not lowering brand surfaces.

Recognition stack (must travel together):

1. **Burnt orange acts; green completes** — semantic split, not rainbow accents. Never purple “AI.”
2. **Arch Bracket geometry** + **split lockup** (mark → `/brand`; wordmark → Today).
3. **Warm ivory light** (`#EDE4D3`) and **charcoal room** (`#1a1a1a` family) — not cool gray SaaS light, not pure void black as brand.
4. **Type jobs** — Bodoni wordmark · Familjen ritual · Figtree product · JetBrains measure. Inter-as-identity is drift.
5. **One capture primitive** on Today — not a tile marketplace.
6. **Human Momentum** tone: precise, honest, non-theatrical.
7. **Page identity via layout ritual** (studio, keep grid, score hero) — not stickers on identical glass cards.

If removing the logo would let the UI pass as another AI SaaS, the design has failed the brand test.

## What makes it feel human

- Starts from utterance and emotion, not schema.
- Correction chips admit the system might be wrong.
- Empty states teach; they do not scold.
- Pattern language over shame language.
- Respect for interruptibility (Focus, stress, urge moments).
- Progressive disclosure that matches emotional stakes (vent vs emergency vault).

## What makes it feel intelligent

Intelligence is felt when:

- The next useful structure appears without being asked for.
- Connections between domains are shown without forcing navigation tourism.
- Coaching points to action (calendar, habit, budget), not platitudes.
- Confidence is visible as chips, not as fake certainty glow.

Intelligence is *not* felt as: decorative gradients labeled “AI”, chatbot chrome as identity, or infinite widgets.

## What makes it feel calm

- Read surfaces (Reports, Insights consumption, Sports) minimize input burden.
- Motion is short, purposeful, opacity+transform — not perpetual celebration.
- Density serves task: Today can be focused; Lab must not be a 14-module carnival as the only entry.
- Orange means action, never alarm-shame chrome.
- One primary action per moment.

## What makes it feel premium

Premium here means **craft restraint**, not luxury ornament:

- Consistent tokens and type roles.
- Confirmations branded, not `window.confirm`.
- No clutter competing with the primary capture or primary read.
- Typography with intent (Familjen / Figtree / JetBrains for brand and scores) — not default Inter stacks as identity.
- Space used as structure; cards only when they hold interaction.

## Visual ideas that must never be used

| Banned | Why |
|--------|-----|
| Purple-on-white / purple-indigo AI gradients | Generic AI SaaS cluster |
| Warm cream + terracotta serif “editorial AI” default | Trend cluster; conflicts with locked ivory/orange system |
| Broadsheet hairline dense newspaper columns as product UI | Wrong cognitive load |
| GoodNotes handwriting chrome | Rejected product path |
| Electric blue system accent | Superseded lock |
| Forest-green WaitlistBrand as Life OS identity | Reverted |
| Glow-heavy “AI magic” ornament | Decorative intelligence |
| Public leaderboard chrome | Anxiety + wrong product |
| Emoji as primary information architecture | Noise |
| Multi-layer shadow card stacks as personality | Clutter |

## Interaction ideas that must never be used

| Banned | Why |
|--------|-----|
| Mode/category gate before capture | Kills intent |
| Duplicate mood / theme / arc pickers | Primitive fracture |
| Dark-pattern upgrade nag loops | Trust break |
| Auto-posting / silent irreversible writes | Ownership break |
| Analytics tools on phone web `/m` | Device lock |
| Clinical diagnostic flows | Ethics |
| Infinite customization as onboarding | Activation death |
| Feature-flag chrome for end users | Confusion |
| Surprising automation during Focus | Interruptibility |
| Social feed as retention | Wrong product |

## Design tensions we accept

| Tension | Resolution |
|---------|------------|
| Power vs beginner | Command Palette + defaults coexist |
| Expressiveness vs calm | Brand/marketing may be expressive; OS stays restrained |
| Light ivory craft vs dark product | Both valid; Palette.md is authority; do not invent third systems |
| Native Material 3 vs web | Same tokens, platform-native behaviors |

## Future impact

Craft sprints may elevate execution quality; they may not invent a new aesthetic family without amending Constitution and Palette.

## Tradeoffs

Locked identity reduces “fresh look” campaigns. Continuity is the brand asset.

## Known risks

- Marketing pages drifting into banned AI looks while product stays locked — still brand damage.
- Craft density creeping into Today until capture is buried.
- Treating premium as more chrome rather than more clarity.
