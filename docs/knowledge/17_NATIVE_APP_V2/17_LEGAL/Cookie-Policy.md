# Cookie Policy — AIIMIN

**`[LEGAL REVIEW REQUIRED]`**

## 1. Scope

Web uses cookies/local storage. Native apps use SDKs and identifiers analogous to cookies (not browser cookies).

## 2. Categories

| Category | Examples | Consent |
|----------|----------|---------|
| Strictly necessary | Auth session, security, load balancing | Required |
| Preferences | Theme, language | Often necessary / preference |
| Analytics | Privacy-safe product analytics | Consent / opt-out by region |
| Marketing | Only if enabled | Consent |

## 3. Mobile identifiers

App instance id, push token, analytics id (non-ads by default). We do not use advertising ID for cross-app tracking without consent.

## 4. Control

Web cookie banner where required. Mobile: You → Privacy / OS settings. Limit Ad Tracking / permission denials honored.
