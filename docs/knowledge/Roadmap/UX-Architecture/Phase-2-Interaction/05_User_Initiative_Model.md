# 05 — User Initiative Model

## Axiom (Genesis)

Human expresses intent; system structures — capture first (P5 twenty-year #2 · Catch spine).  
AI is **mixed-initiative**: acts when confident, suggests when uncertain, asks when necessary (P5 #4).

## Initiative parties

| Party | May initiate | Must not |
|-------|--------------|----------|
| **User** | Capture, navigate, command, configure, dismiss | Be blocked from Catch by structure ceremony |
| **System (deterministic)** | Sync banners, tier locks, auth gates, loading/empty/error states | Shame nags; vanity notifications |
| **AI** | Offer / suggest / draft within confidence + correction | Silent-wrong writes; clinical labels; Knock during Hold; decorative AI |

## User initiative paths (Intelligence-evidenced)

| Path | Surfaces | Rule |
|------|----------|------|
| Capture | `/m`, logger, journal, notes | Ungated Catch; Enter/primary save |
| Command | Palette | Desktop keyboard initiative |
| Plan/Exec | Goals, habits, focus, discipline | User starts; system feedback |
| Review | Today, Reports | Calm read; derived not fake write |
| Configure | Account/Settings | Explicit user open |

## System initiative limits

| Allowed | Forbidden |
|---------|-----------|
| Surface state (loading/empty/error/offline/sync) | Engagement drip without value (IX-9) |
| Tier/permission denied with clear next step | Dark-pattern upgrade (NN) |
| Sync/conflict signals | Inventing new interrupt windows (DH-23) |

## AI initiative — see [[09_AI_Interaction_Model]]

Confidence bands + confirm/correct — never ambush (IX-2).
