# 02 — Component Taxonomy

Taxonomy = architectural families from Intelligence inventory. **No new families invented** beyond evidence + Genesis primitive law.

## Tier model

| Tier | Meaning | Examples (Intelligence) |
|------|---------|-------------------------|
| **T0 Primitive** | Cross-product atoms | Button · Input · Textarea · Badge · Tooltip |
| **T1 Feedback** | System feedback | Skeleton · EmptyState · StatusAlert · LiveRegion · ConfirmDialog · Modal · Drawer |
| **T2 Navigation** | Shell / find | BrandLockup · Navbar/masthead · BottomNav · MobileBottomNav · TabRail · CommandPalette |
| **T3 Capture** | Sacred write | Logger/capture sections · MoodSelector · PIN entry patterns · `/m` capture forms |
| **T4 Domain row** | List/entity rows | TaskRow · HabitCircle · FamilyCardMenu · DeadlinePicker |
| **T5 Metric/Read** | Calm derived read | **One** Metric primitive family (MERGE Hero/Tile/Metric) · AnimatedNumber |
| **T6 Chart** | Selective viz | charts/* — subset KEEP; not identity system |
| **T7 Domain shell** | Heavy domain | FocusRoom locals · Finance drag zone behavior · Career kanban |
| **T8 Marketing** | Public only | waitlist/* — isolated |
| **T9 Experimental/Parallel** | Audit/KEEP subset or REMOVE | kokonutui/* · DesktopWindow |
| **T10 Native** | Compose kits | Native shared UI — contract-aligned, render-separate |
