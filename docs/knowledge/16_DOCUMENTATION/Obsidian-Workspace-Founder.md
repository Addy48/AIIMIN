# Workspace setup — Founder

## One-time (Obsidian UI)

1. Open [[15_MEMORY/Current-Context]] in main pane.
2. Split right: [[Dashboards/01_Executive-Dashboard]] (or Daily Ops).
3. Left sidebar: Bookmarks (Core group already in `.obsidian/bookmarks.json`).
4. Right sidebar: Backlinks.
5. **Save layout** as workspace named `Founder` (Command palette → “Manage workspace layouts”).
6. Optionally save `Ops` / `Law` / `Build` / `Decide` / `Hygiene` per [[Roadmap/Program-V1-Obsidian-Knowledge-OS/12_Workspace_UX]].

## Plugins

Community plugins **vendored** under `.obsidian/plugins/` (Dataview · Templater · QuickAdd · Metadata Menu · Omnisearch). Enable Community plugins → trust/enable listed ids in `community-plugins.json` (count **5** ≤8).

Templater folder: `_templates`. Capture macros: `qa-bug` · `qa-adr` · `qa-feature` · `qa-eng` · `qa-inbox` · `qa-touch`.
